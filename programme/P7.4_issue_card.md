## How locality is asserted, and against which graph

The authority is `assets/equation-graph.v1.json` — 39 nodes, 71 edges — read through `activeEquationEdges(EQUATION_GRAPH, circularity)`, the same activation filter P4.7's solve-time Tarjan pass uses. For a perturbation of node N in a case whose `controls.circularity` is c:

- `may_move` = {N} ∪ forward-reachable(N, c);
- `must_not_move` = every observable node outside that set;
- the observed change set is computed field-by-field from the two solutions and intersected with `must_not_move`. A non-empty intersection is an ESCAPE.

The observable plane is a declared bijection, enforced at module import against the graph: all 39 nodes appear exactly once, 26 with a forecast field and 13 with a stated reason they have none (P4.6's declared instrument/schedule coverage gap, bridge rows the record does not expose, and the solver control which carries no quantity by construction). Five totality mutations prove the check bites: an undeclared node, an orphan declaration, an unreasoned absence, a contested field and an unclaimed field are each caught.

`statement.effective_tax_rate` is the tightest claim the graph makes — one outgoing edge, reaching two nodes. Twenty-four observables may not move. `cash.minimum_cash` at circularity 1 reaches twenty nodes through the interest–cash fixed point, and the twelve it may NOT reach (EBIT, the tax rate, the whole debt schedule, the lease, every per-instrument interest node, the RCF capacity) are asserted unchanged on all 31 archetypes and all 92 generated cases — **31/31 and 92/92 held outright, with zero vacuous cases**. That is the first locality relation in the repository that passes clean.

## The five real non-invariances found — recorded, not repaired

All five are registered in `assets/metamorphic-relations-v1.json :: known_defects` with a reproducing case or seed, a repair owner, and a retirement condition. Every one lives in a file this package is forbidden to touch. No relation was weakened to accommodate any of them; each escape is PINNED to exactly its declared shape and the suite fails if it widens **or if it stops reproducing**.

**MG-1 (high) — the canonical equation graph omits `statement.tax_expense → cash.cfo`.** Reproducing case `test-fixtures/archetypes/economics/deferred_revenue_ratable.json`: append an `effective_tax_rate` row and solve. `tax` moves 0 → 42.27117623444384 and `cash_from_operations` moves 282.18090452260935 → 239.69731031714127. The graph gives `statement.tax_expense` exactly one outgoing edge, to `statement.net_income`, and anchors the cash flow at `statement.ebit`, so no path exists. 24 of 31 archetypes and 66 of 92 generated cases escape, and **every escape is accounted for by that single missing edge**. Second-order consequence, asserted separately: the missing edge closes the cycle tax → cfo → ending_cash → cash interest income → finance income → pre-tax income → tax, and `assets/convergence-contract.v1.json` declares ONE active SCC of 13 nodes for circularity 1 containing neither `statement.pre_tax_income` nor `statement.tax_expense` — both of which are observed moving. The declared fixed point understates the solver's real fixed point.

**MG-2 (medium) — the graph has no debt or lease BALANCE node, so six balance-movement → accrued-interest edges are absent.** `lease.principal → interest.lease`; `debt.scheduled_amortisation → interest.instrument_cash` and `→ interest.instrument_pik`; `debt.issuance → interest.instrument_cash`, `→ interest.instrument_pik` and `→ debt.maturity_repayment`. P4.6 declares the instrument and lease families uncovered, but as ROW realisation; this states the same gap as concrete missing EDGES, which is what a locality relation needs.

**MG-3 (high) — solver convergence is not scale-invariant.** `test-fixtures/archetypes/economics/revolver_undrawn_commitment_fee_only.json` converges in 6 iterations with residual 6.0370997090331e-10 against an ABSOLUTE `convergence_tolerance` of 1e-8. Restated from millions into thousands — the same economics — it throws `SOLVER_NON_CONVERGENCE` in forecast period 2027-12-31, because the residual scales with the magnitudes and `SOLVER_ITERATION_POLICY.tolerance` (`scripts/lib/solver.mjs:1662`) does not. An issuer that reports in thousands can be refused for economics an issuer reporting in millions is served. One generated case reproduces it too. The suite asserts the cause directly (residual × 1000 > tolerance) rather than only the symptom.

**MG-4 (medium) — a `row_type: header` row, which declares no values at all, is materialised into `statement_values` as numeric 0.** Found by `repeated_header`. No solved economic quantity moves, so the family stays declared economics-preserving, but the delta is PINNED: only `statement_values`, only keys with the inserted prefix, only the value 0, no key removed, no other field changed — and a mutation proves a non-zero minted value breaches the pin. The repository's own doctrine is that an absent value never becomes a number. Also observed and recorded: the trailing repeated header does NOT appear while the leading one does, so two identical rows are not treated identically.

**MG-5 (low today, latent) — the opening-debt bridge residual is order-dependent.** Found by `row_reorder_instruments` on the refusal plane. Seed 700577 refuses reporting -943.56 USD unexplained; reversing the instrument array — every instrument keeping its own `display_order` — refuses reporting -943.5600000000002. The bridge sums the register without a canonical order. 26 drifts observed, all ~1e-13 relative against a bridge tolerance of 0.01, so no verdict flips today. It is registered because a residual within ~1e-12 of the tolerance would flip on register order alone. The refusal-plane comparison therefore compares the literal message text EXACTLY and its embedded magnitudes at a declared relative epsilon of 1e-9, with the observed bound asserted so the dependence cannot widen unnoticed, and with drift from any family other than the register permutation treated as a NEW defect.
