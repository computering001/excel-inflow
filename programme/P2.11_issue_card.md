## Repair direction chosen, per defect

- D13, the three cases where the intake states an unsupported or unstated value — direction (a), MAKE THE STOP FIRE. An UNSUPPORTED profile should stop, typed, before the model runs; the declaration was already honest and the predicate set was simply incomplete. `insufficient_history_stop` and the new `unsupported_accounting_framework_stop` now key on "the dimension verdict is UNSUPPORTED" rather than on a literal value, which is what covers the unstated case (silence takes the declared `unknown_value_class`, and for both dimensions that class is UNSUPPORTED). A residual backstop predicate (`unsupported_dimension_residual_stop`) makes the invariant structural rather than enumerated: any future declared value whose class is UNSUPPORTED stops typed instead of running on untyped. The suite proves every value declared TODAY is covered by a NAMED predicate, so the backstop can never become an excuse for an unnamed refusal, and proves the backstop works by mutation.
- D13, the fourth case (`non_english` with a declared adapter) — the DECLARATION was wrong at the dimension level. A versioned language adapter is the declared mechanism that brings a non-English filing inside the envelope, and `unadapted_language_stop` already reads that fact; before this change the adapter lifted the STOP but not the VERDICT, so the case classified UNSUPPORTED and ran on. Direction (a) is unavailable here: firing the stop anyway would make the declared adapter dead, contradicting the predicate's own rule text and its declared negative examples. The repair is a contract-declared `conditional_class_lift` on the dimension, read by the classifier from the contract, lifting `non_english` to EXPERIMENTAL — never CERTIFIED — when the adapter flag is present. An adapter makes no certification claim until it clears `EXPERIMENTAL_to_CERTIFIED` promotion evidence, so EXPERIMENTAL is the honest ceiling.
- D14 — direction (b), WIDEN THE DECLARATION, because the declaration itself was wrong. The experimental ring is a CERTIFICATION statement, not an evidence or ownership statement. An experimental-ring case can still be missing mandatory evidence (SOURCE_REQUIRED) and can still face a choice that genuinely belongs to the user (ACTION_REQUIRED); those outcomes arise AFTER preflight, in any ring, and refusing to name them does not stop them happening. Excluding them was the error, and the case having no lawful terminal was the symptom. This is NOT a weakened validator: nothing about the certification claim changes, DELIVERED_VERIFIED stays unlawful for EXPERIMENTAL, and the widening is BOUNDED — the suite asserts that UNSUPPORTED must NOT admit those terminals, because it stops before the layers that produce them. The widening was not made to pass a test: the suite states the rule (a class the run continues in must admit every terminal a continuing run can produce) and the mutation section proves that narrowing EXPERIMENTAL back is caught for all three outcomes.
