## Difference classification
- Intended correction: a reverse reader whose expectation is the RECORDED PLAN and whose observation is the .xlsx package bytes — nothing else. `reconstruct_plan()` rebuilds a plan-shaped description of the workbook from `zipfile` + `ElementTree` (with openpyxl's published builtin-number-format table for `numFmtId` resolution, and openpyxl as a second, third-party reader whose disagreement is itself the typed finding `RECON_READER_DISAGREEMENT`), and `compare()` reports a typed finding for every disagreement in either direction. Twenty-four workbook aspects are reconstructed and compared, including the seven the GAP named as unread: comments (cell AND text, plus the author resolved through `xl/persons/person.xml`), conditional formats (with the dxf RESOLVED on each side, because the emitted package deduplicates 120 recorded differential styles into 9 `dxfs`), data validations, number formats, merges, column widths and `calcPr`; freeze panes, row heights, outline properties, page margins, page setup, defined names, gridlines, default font and drawing anchors/media hashes as well. Style and differential-style INDICES are never compared — 203 recorded styles become 202 `cellXfs`, so each side dereferences its own table and the resolved records are compared field by field. Effective values are compared rather than spellings (`C4:C4` == `C4`; an absent `<outlinePr/>` == `summaryBelow="1" summaryRight="1"`). Beyond the enumerated channels, a part-scoped unmapped sweep makes going blind a failure rather than silence: every element and attribute in `xl/workbook.xml`, each worksheet, `xl/styles.xml` and each comment part is either read into the reconstruction, named in the report's `unrecordable_surfaces` (28 observed, e.g. `element:selection`, `attribute:xf@xfId`, `threaded_comment_person_ids` — content the plan schema has no field for), or a blocking `RECON_UNMAPPED_XML_ELEMENT` / `RECON_UNMAPPED_XML_ATTRIBUTE`.
- Regression: none — no existing file is modified. Both certified fixtures reconstruct to a clean PASS on the first honest run, so the emitted workbooks are shown to carry nothing the recorded plans do not account for.
- Unresolved: the fixtures carry ZERO merges, so the merge channel is exercised only by mutation (a merge injected into the .xlsx and a merge recorded in the plan with no counterpart in the file) rather than by corpus content — recorded here rather than left implicit. Both fixtures also carry no images and no `pageSetup`/`definedNames` content, so those channels are reconstructed-but-unexercised. Five declared coverage gaps are carried in every report (`declared_gaps`): the plan's `images[].path` (the .xlsx holds media bytes, not source paths — anchor and sha256 ARE compared); `plan_version`/`case_id`/`generator` (provenance of the plan document, absent from the workbook by construction); cached-value TRUTH (this oracle proves file↔plan agreement, not that either is the right arithmetic — that belongs to a recalculation oracle); `apply*` style-inheritance flags (the package has one default style parent, so the xf's own values are effective); and shared/array formula expansion (`t`/`ref`/`si` are recorded and compared but not expanded — the emitted package writes every formula in full).
